# TaskFlow Mobile

The managed Expo application currently runs from the repository root so the WebDev preview, Expo Router entrypoint, and existing platform configuration remain stable. This directory is the intentional mobile workspace boundary for a later extraction into a standalone package once backend contracts and shared packages are finalized. The mobile design plan and reusable components are implemented in the root `app/`, `components/`, `constants/`, `hooks/`, and `lib/` directories for Iteration 1.
